# ふたりの日

ふたりの記念日を数える、シンプルな Web アプリです。iPhone のホーム画面に追加すると、普通のアプリのように使えます。

**公開ページ:** https://kaztsuka04-sudo.github.io/couple-days/

<img src="icon-512.png" width="96" alt="ふたりの日のアイコン">

## できること

- **日数のカウント**: はじまりの日を1日目として「今日で◯日目」を表示します。数字をタップすると「◯年◯ヶ月◯日」「◯週◯日」に切り替わります。
- **次の記念日**: 毎月の記念日(◯ヶ月記念・◯周年)までの残り日数を、進み具合のバーと一緒に表示します。
- **これからの記念日**
  - 「日数」「日付」「毎年」の3通りで登録できます。誕生日などは「毎年」にすると毎年くり返し表示されます。
  - 100日・200日…1000日、1111日などの節目は自動で一覧に加わります(設定でオフにできます)。
  - 過ぎた記念日は「過去の記念日」にまとめて表示します。
- **カレンダー**: 祝日・土日・記念日を色分けして表示します。左右にスワイプで月を移動し、下にスワイプで閉じます。祝日は1949年以降の祝日法の改正に合わせて計算しています。
- **共有メニュー**(左上のボタン)
  - **記念日カード**: 「今日で◯日目」の画像を作り、LINE などで共有したり写真に保存したりできます。
  - **共有リンク**: 同じ設定を相手のスマホに渡せます。設定はリンクの `#` より後ろに入っているので、サーバーには送られません。
  - **カレンダーに登録**: `.ics` ファイルを書き出して iPhone のカレンダーに追加できます。前日と当日の朝9時に通知が届きます。
- **テーマカラー**: 6色から選べます。
- **バックアップ・復元**: 設定を JSON ファイルに書き出したり、そこから読み込んだりできます。
- **オフライン対応**: 一度開けば、電波のない場所でも起動できます。
- **ダークモード、iOS の文字サイズ設定、視差効果を減らす設定、VoiceOver** に対応しています。

## iPhone での使い方

1. Safari で公開ページを開きます。
2. 共有ボタン →「ホーム画面に追加」をタップします。
3. ホーム画面のアイコンから起動し、「はじまりの日」を設定します。

## データについて(大事なこと)

- 設定はその端末のブラウザの中(localStorage)だけに保存されます。外部には送信されません。
- **Safari とホーム画面に追加したアプリでは、保存場所が別々です。** Safari で設定してからホーム画面に追加すると、アプリ側は空の状態から始まります。
- 機種変更や、以前のページから移るときは、次のどちらかでデータを移してください。
  - 設定 →「バックアップを書き出す」で保存したファイルを、「バックアップから復元」で読み込む
  - 共有メニュー →「相手に共有リンクを送る」で作ったリンクを、設定 →「共有リンクから読み込む」に貼り付ける
- 以前のバージョン(`couple-days-v1`)のデータは、同じ場所で開けば自動で引き継がれます。

## 技術メモ

- ビルド不要の静的ファイルだけで動きます(`index.html` / `manifest.webmanifest` / `sw.js` / アイコン)。外部ライブラリは使っていません。
- GitHub Pages(`main` ブランチの直下)で公開しています。
- 新しいバージョンを公開するときは、`sw.js` の `CACHE` の名前を変えると、古いキャッシュが確実に入れ替わります。
